# ubuntu_additions
A script that installs applications for you using APT.
Coming soon:

Steps:

Open up the terminal

Type: <chmod +x ubuntu_additions_your_version_here.sh>

Then: <./ubuntu_additions_your_version_here.sh> (the <> is just there to signal what you need to type, same 
with the your_version_here)
